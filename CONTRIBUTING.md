# Contribuir

1. Crea una rama para cada cambio.
2. Ejecuta `npm test` y `npm run check`.
3. No incluyas cookies, tokens, archivos descargados ni URLs privadas en pruebas o incidencias.
4. Mantén los adaptadores de plataforma dentro de `yt-dlp`; evita extractores frágiles duplicados en JavaScript.
5. Explica los cambios visibles y sus pruebas en el pull request.

Las contribuciones deben respetar derechos de autor, condiciones de las plataformas y la legislación aplicable.
